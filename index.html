Strain is cumulative axial strain (%) from the start of the test. Rows keep the order you enter them in. A point is auto-flagged Load if its stress is a new maximum for the test, otherwise Rebound (unload/reload) — this keeps an unload branch from distorting the Casagrande curvature search or the virgin line. Check Cr on either branch (an unload leg usually gives the cleanest estimate); check Cc only on the straight-line loading branch.

Reference state

e₀ is the void ratio at the start of the test (assumed to equal the in-situ void ratio). It converts strain to void ratio internally (e = e₀ − ε·(1+e₀)) and anchors the recompression line and the 0.42e₀ correction.
